# Enterprise Process Mining & Intelligent Workflow Optimization

Designed and developed an end-to-end Purchase-to-Pay process intelligence
platform using Python, PM4Py, Power BI, PostgreSQL, FastAPI, Docker, and BPMN.
Built a deterministic synthetic benchmark with 12,000 cases and 166,551 events;
discovered process variants, measured conformance, identified bottlenecks and
rework, and developed an explainable temporal-holdout SLA risk model.

Translated findings into capacity decisions through replicated queue-network
simulation. The recommended combined intervention modeled a 19.42% cycle-time
reduction, 13.63 percentage-point SLA uplift, $2.21M annual value, and 8.84x
first-year ROI under explicit synthetic assumptions.

Delivered a read-only API, governed PostgreSQL model, Power BI developer kit,
decision workbook, BPMN target process, observability stack, CI/security
controls, 58 automated tests with 96.97% coverage, and bilingual executive
reporting. All data and business-impact estimates are synthetic.
